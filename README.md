📈 **Excel Business Analytics & Data Cleaning Models**

A collection of practical business reporting and data cleaning projects developed using Microsoft Excel.

This repository showcases hands-on data manipulation and business analysis skills from the **IBM Data Analyst Professional Certificate** program.

---

🎯 Featured Projects

1. Fleet Inventory Data Cleaning & Pivot Analysis (`Data/`)
* **Focus:** Asset tracking, data wrangling, and operational reporting on the Montgomery County fleet dataset.
* **Techniques Used:** Data cleaning (trimming, deduplication, standardizing categories) and multi-level **Pivot Tables** for executive summaries.
* **Outcome:** Cleaned unstructured fleet records and built aggregated summaries by department and equipment category.

2. Car Sales Performance Model (`Data/`)
**Focus:** Automotive sales performance, dynamic KPIs, and trend modeling.
**Techniques Used:** Lookup functions (`XLOOKUP` / `VLOOKUP`), conditional formatting, Pivot Tables, and interactive Pivot Charts.
**Outcome:** Transformed raw sales data into a structured model to evaluate regional and model-level performance.
